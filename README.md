# 📖 About

**Character Forge** is a fantasy-inspired character card generator that lets you create beautiful RPG-style character profiles with live previews.

Customize your hero with a name, class, race, level, avatar, stats, skills, biography, and color themes, then export the finished character card as a high-quality PNG image.

Built entirely with **HTML, CSS, and Vanilla JavaScript**, Character Forge focuses on responsive design, dynamic UI updates, and image exporting without any frameworks.

### 1️⃣ Create Identity

- Character Name
- Class
- Race
- Level

---

### 2️⃣ Upload Avatar

Choose your own character portrait.

Supported formats:

- PNG
- JPG
- GIF

### 3️⃣ Customize Stats

Adjust:

- 💪 Strength
- 🏃 Agility

- 🧠 Intelligence
- 🛡 Defense
- 🍀 Luck

using interactive sliders.

### 4️⃣ Add Skills

Examples:

- Arcane Surge
- Fireball
- Shadow Strike
- Healing Light
- Time Warp
- Berserk

### 5️⃣ Write Character Lore
